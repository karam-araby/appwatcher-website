# AppWatcher website

Static bilingual website for **AppWatcher — حارس الجوال**. It is designed for
GitHub Pages and has no build step or external runtime dependencies.

## Local preview

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Publishing

GitHub Pages should deploy from the repository root on the `main` branch.

The product description and privacy policy match AppWatcher 1.1: local incident
analysis, one Google Mobile Ads native placement after non-empty results, and no
AI or package-name upload.
